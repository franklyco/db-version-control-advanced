Connected Environments — state vocabulary

Every state string the page can render, grouped by the six tones in TONES (src/connected-app/index.js). The mapping is toneFor(); an unlisted state falls back to neutral. Toggle dark to check both themes against the same tokens the app ships.

Positive

Agreement, success, an enabled/present/enrolled steady state.

Directional

A pending or in-flight direction of travel (outgoing/incoming, requested, approved, selected).

Neutral

A settled non-judgemental fact (converged, noop, baseline required, observed, withdrawn/detached).

Caution

Drift, version distance, a hold or a stale/incomplete read — attention, not failure.

Negative

Conflict, failure, compensation, revocation — something did not or cannot proceed.

Uncertain (dashed)

Not knowable right now: unknown, unsupported, not observed, incomplete, unavailable, disabled. Never reads as clean.
