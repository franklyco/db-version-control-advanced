# UI Reference Images

These PNGs are initial concept sketches. They are not pixel-perfect specifications and may contain illustrative labels or controls that are not approved for production.

| File | Concept |
|---|---|
| `reference-images/01-frontend-website-manager-shell.png` | Persistent frontend Website Manager shell and toolbar continuity |
| `reference-images/02-registry-brand-control-center.png` | Registry-backed Brand Control Center list/detail concept |
| `reference-images/03-frontend-site-manager-workspace.png` | Object navigation workspace concept |
| `reference-images/04-media-manager-initial-concept.png` | Scrollable missing-image findings table with expanded field rows |

## Usage rules

- Use them to communicate visual hierarchy, density, and frontend context.
- Codex must define current data/actions/states before Claude refines static HTML/CSS.
- Do not copy visible field names, counts, routes, timestamps, `Publish`, or bulk controls as requirements.
- The Media Manager image’s cross-entity `Save selected` concept is not approved for R1/R2.
- The Media Manager image’s `Upload New` action means opening WordPress core Media Library/upload, not a custom uploader.
- Production styling must map to current DBVC tokens/components and accessibility requirements.
