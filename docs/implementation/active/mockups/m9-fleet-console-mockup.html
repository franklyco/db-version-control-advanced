1 · Framework object, unchanged by the client

The official version wins. The push brings the site up to date. In sync ← synchronized

2 · Framework object the client locked

The client's version wins on their site; the push skips it. If the update changes that same object, it's flagged Needs review — keep, re-apply, or unlock. Never silently overwritten. Client customization ← approved_override

3 · Client-owned original object

Their own class or template, never part of the framework. Never touched, never flagged as drift. client-owned ← out of scope

This ownership model is what lets one hub push update the whole network while every site keeps its approved custom work.
